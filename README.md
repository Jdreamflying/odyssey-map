# 奥德赛证据地图

vibe coding了奥德赛的地点地图
标注了航线上各个位置的情况，也让大家对奥德赛中的具体行程有一个直观的了解
方便大家观影前后来熟悉情节
欢迎大家收藏、关注

荷马《奥德赛》十三站的可视化证据分布图。

**十三站，十二站今天能去，四站有考古遗存，零站能证明奥德修斯到过。**

这不是一张行程图，是一张证据分布图。它把三件经常被混在一起说的事情分成三层：

- **史诗记载** —— 荷马原文写了什么
- **学术推测** —— 后世学者把它对应到哪里，凭什么
- **考古证据** —— 那个地点上到底挖出了什么

## 三个标签的含义

| 标签 | 判定标准 | 站数 |
|---|---|---|
| 有考古遗存 | 被指认的地点上有已发掘的遗存，**且该地名在史诗之外独立可考** | 4 |
| 学术推测 | 有学者提出对应关系并给出理由，但缺少上述两条中的至少一条 | 4 |
| 后世指认 | 对应关系由后人指认，或史诗的描述本身即不可能成立 | 5 |

第一条的后半句是关键。若只要求「地点上有考古遗存」，埃埃亚岛（尼安德特人头骨）、利帕里（黑曜石贸易）、科孚（戈尔贡三角楣）都能算进来，变成七站——但那些地方的名字是**从神话反向命名**的，命名方向反了。加上「地名在史诗之外独立可考」这一条，正好是四站：特洛伊（赫梯文书 Wilusa）、伊斯马罗斯（马罗尼亚的酒名沿用至今）、冥府入口（阿刻戎河今仍名阿刻戎）、伊萨卡（伊萨基岛名沿用至今）。

其中伊萨卡和冥府入口两站标了 †，表示学界仍在争论。

## 站点顺序

**依故事时序排列，不是卷次顺序。** 俄古癸亚出现在卷五，斯刻里亚在卷六至卷十三，而奥德修斯亲口讲述的漂流（卷九至卷十二）在故事时间上更早。

## 技术

单文件，零外部依赖。HTML + 内联 CSS + 原生 JS + 内联 SVG，没有字体外链、没有图片外链、没有 CDN。直接用浏览器打开 `index.html` 即可。

- 地图为等距圆柱投影，海岸线为手绘概化多边形
- 支持浅色 / 深色两套主题（跟随系统）
- 竖屏适配（手机浏览时地图收窄、隐藏标签、十三点同框，无横向滚动）
- 键盘左右方向键切换站点
- 尊重 `prefers-reduced-motion`

## 参考文献

见页面底部「出处」一节，共 25 条。其中两处需要特别注意，页面内也已标出：

- 赫西俄德《神谱》1011–1016 那几行**普遍被认为是后人增补**
- 伊萨基「荷马学校」遗址的主要发掘者**不是中立方**（其专著即名为《The Archaeological Evidence for the Palace of Odysseus on Ithaca》，序言称结果「被掩盖」）

修昔底德 1.25 与 6.2 **两处均为转述，非表态**。
