# 古地图美术资产

这里放 17–18 世纪铜版航海图风格的图元。地图的装饰**正在从「程序生成」迁到「外部资产」**，
本目录就是资产这一侧。

## 为什么在 public/ 而不是 src/

Vite 只把 `public/` 下的文件按**原样路径**对外提供。放在 `src/assets/` 的文件必须
逐个 `import` 才能拿到打包后的哈希路径，那样每加一张图都得改一次代码 —— 与
「把文件丢进目录就能用」的目标相反。所以资产放这里，清单
（`src/data/cartographyAssets.js`）里只写相对路径，加载时再拼上 `BASE_URL`。

⚠ 不要把 `src` 写成 `/assets/...` 这种绝对路径：本项目 `vite.config.js` 里
`base: './'`，绝对路径在子目录部署时会 404。写相对路径即可。

## 目录

| 目录 | 放什么 | 类型名 |
|---|---|---|
| `mountains/` | 山脉、丘陵、火山 | `mountain` |
| `ships/` | 帆船、桨船 | `ship` |
| `sea/` | 海怪、鲸、波浪刻线、漩涡 | `sea` |
| `settlements/` | 城堡、城镇、港口、塔楼 | `settlement` |
| `navigation/` | 罗盘、风玫瑰、恒向线枢纽、比例尺 | `navigation` |
| `notes/` | 手写注记、饰框、卷轴题记、纹章 | `note` |

## 单个资产的要求

- 格式 `.svg` 或 `.png`（两者都支持，`.svg` 优先 —— 放大不糊）
- **背景必须透明**，不要白底
- 只用墨色（深褐 / 黑），不要彩色 —— 它要像印在羊皮纸上的墨迹
- 画面裁到内容边界，四周不要留大片空白（留白会让定位偏移）
- 线条按「铜版雕刻」处理：细实线 + 排线，不要现代插画的色块与渐变

## 尺寸约定

清单里的 `scale` 是**渲染高度占地图高度的比例**，不是像素倍率。
宽度由图片自身长宽比自动算出，不需要手填。

参考 18 世纪地图的比例：

| 类型 | 建议 scale | 约合高度 |
|---|---|---|
| 山脉 | 0.03 – 0.08 | 19 – 52 图单位 |
| 帆船 | 0.02 – 0.04 | 13 – 26 |
| 海怪 | 0.03 – 0.06 | 19 – 39 |
| 城堡 / 港口 | 0.012 – 0.025 | 8 – 16 |
| 罗盘 | 0.06 – 0.12 | 39 – 78 |
| 注记 / 饰框 | 0.02 – 0.05 | 13 – 32 |

（地图 viewBox 是 989 × 648 单位，所以「地图高度」= 648。）

开发模式（网址后加 `?debug`）会检查山脉是否落在 3%–8% 之外并在控制台告警。

## 加一张图的完整流程

1. 把文件丢进对应目录，例如 `mountains/apennines.svg`
2. 在 `src/data/cartographyAssets.js` 的 `CARTOGRAPHY_ASSETS` 里加一条：
   ```js
   { name: 'apennines', type: 'mountain', src: 'mountains/apennines.svg',
     lon: 13.4, la: 42.2, scale: 0.06, opacity: 0.38, rotation: -8 }
   ```
3. 刷新页面。带 `?debug` 时控制台会报告这条资产落在海里 / 压住航线 / 尺寸超范围。

⚠ **同一类目只要有一条资产，该类目的程序生成版本就自动关闭。**
也就是说放进第一座山的那一刻，`reliefPen` 画的所有山脉排线一起停画，
避免两套东西叠在一起。想手动控制见 `cartographyAssets.js` 里的 `CATEGORIES`。
