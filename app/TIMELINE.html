ODYSSEY TIMELINE

十二节点航程表

Visual Bible 卷二 · 十二图版 · 第一版

本表承 Visual Bible 全部法则，把航程切成十二个节点。每个节点给定五项：名目、史事、视觉描述、镜头运动、转场。五项齐备即可直接出图与实现，不需再作解释。

十二节点分三卷，每卷四节：城是陆上的战争，海是失去参照的漂流，渊与归是下降到最深处再浮上来。这个三段结构决定了后面镜头强度的全部起伏——它不是均匀铺开的十二幕，是一条有两个峰、一个谷、一段静止收尾的曲线。

镜头强度弧Camera Intensity Arc · 十二节点

先看整条曲线，再看单个节点。任何一节的镜头参数都是这条弧线上的一点，不能孤立调整。

强度按 0.6 × 平移幅度 + 0.4 × 推近幅度 归一化得出，与后文各节点的实际参数一一对应。两个峰是波塞冬（VII）与斯库拉（X）；第八节塞壬是全篇唯一的深谷——那里的危险来自静止，镜头几乎不动，这是整条弧线上最重要的一次反直觉设计。

Fig. 1 — 镜头强度弧。柱体以 45° 排线填充，不用实色（承第 II 版）。密排线柱为强度 ≥ 68 的高张力节点。悬停可见节点名。

转场词汇Transitions · 五式

全篇只用五种转场。每个节点的转场即该节点的离开动作，不另设中间态。

五式各有其义，不可互换：揭页是翻过一页，沉降是沉入水与土，洇墨是意识失守，落幕是一卷终了，定影是照片显影完成后不再变化。选用哪一式由内容决定，不由节奏决定。

Α 卷一 · 城 Nodes I–IV · The City
I

Troy War Begins

特洛伊战争爆发

需出图
史事
希腊联军为夺回海伦渡海东征，千帆抵达特洛伊海岸。十年围城自此开始，奥德修斯本不愿前往，被迫离开新生的儿子。
视觉
黎明前的特洛伊平原，城墙盘踞于远景高地，轮廓由细密排线勾出。中景是刚登陆的船首与竖起的长矛，前景为一段被踩倒的草坡。天空以发丝线横向退晕，全画最亮处是城墙上方那道未刻的留白。光源左上。
镜头
缓慢右移，几乎不推近——战争尚未开始，镜头还在观望。bg x +70 · scale 1.02 · fg x −40
转场
揭页opacity 1→0，x 0→−240。平铺直叙地翻过去。
II

Greek Army March

希腊军队开拔

希腊军队.png
史事
联军在滩头列阵，向城墙推进。十年间这样的行军重复了无数次，胜负始终未决，人一批批死去，城墙一寸未破。
视觉
横向铺满画面的军阵，长矛构成密集的斜向线群——这是全篇排线密度最高的一幅，接近 55% 上限。盾牌以圆形留白打断矛林的节奏。远景城墙被压得极低，只余一线。前景一名士兵背影入画不完整，被画框裁断。
镜头
大幅左移，几乎不推近。纯粹的横移读作「巡视」，望不到头。bg x −120 · scale 1.01 · fg x +70
转场
揭页同上。两节连用揭页，建立平稳的基准节奏。
III

Fall of Troy

特洛伊陷落

特洛伊陷落.png
史事
木马入城，当夜城破。奥德修斯是木马计的献策者——他赢得了战争，也由此招来了神的记恨。
视觉
第一个高张力节点。城门洞开，火光自城内涌出，火不用亮部表现，而用周围骤然加密的排线反衬。木马巨大剪影立于前景左三分之一外，以最粗的剪影线（1.6）勾勒。烟柱向左上倾斜，与光源同向。倒塌的梁柱在中景形成对角线。
镜头
右移并明显推近，画面第一次向内收紧。bg x +100 · scale 1.08 · fg x −60
转场
沉降opacity 1→0，y 0→+180。城塌下去，画面跟着沉下去。
IV

Odysseus Departure

奥德修斯启航

希腊船队.png
史事
战争结束，船队起锚返乡。所有人都以为几周即可到家。这是十年漂流的起点，也是最后一次风平浪静。
视觉
船队自左向右驶离，帆以大面积留白处理，是全画最亮的部分。海面排线平缓、间距均匀——这种「过于平静」的排线在后面五节都不会再出现，构成对比。远景特洛伊只剩一道极淡的发丝线轮廓，几乎要消失。
镜头
纯右移，零推近。全篇唯一 scale 保持 1.00 的节点——镜头在放手，不再靠近。bg x +110 · scale 1.00 · fg x −55
转场
落幕opacity 1→0，scale 1→1.06。卷一终，铜版被提起。
Β 卷二 · 海 Nodes V–VIII · The Sea
V

Storm at Sea

海上风暴

需出图
史事
归途上第一场大风暴，船队被吹散，从此再没有回到航线上。奥德修斯失去了同伴，也失去了方向。
视觉
浪自左上压下，浪脊用最密的三道排线，浪谷留白。船被顶到画面右上，倾斜近 30°，桅杆断裂。云与浪的排线方向一致，形成一个贯穿全画的巨大斜向漩流。地平线消失——这是全篇第一次没有地平线的构图。
镜头
左移并带下沉的 y 位移，推近中等。bg x −105 · y −18 · scale 1.06 · fg x +60
转场
沉降船沉下去，画面沉下去。
VI

Island of Cyclops

独眼巨人之岛

独眼巨人.png
史事
登岛求食，被独眼巨人波吕斐摩斯困于洞中。奥德修斯自称「无人」，刺瞎巨人独眼后脱身——而巨人是波塞冬的儿子。
视觉
洞穴内部，钟乳石自上垂下切割画面。巨人占据右侧三分之二，独眼是全画唯一的圆形留白，也是视觉焦点。火堆在左下，用加密排线表示其周围的暗，而非画出火焰。洞口在远景，是一道刺目的白——出路极小。
镜头
推近取全篇最大值 1.09，横移反而收小——洞穴在向内收拢。bg x −80 · scale 1.09 · fg x +50
转场
揭页逃脱成功，干脆地翻过去。
VII

Poseidon Appears

波塞冬显现

波塞冬.png
史事
为子复仇，撼地者亲自出手。此后每一朵浪都带着神的名字，回家变成一件被诅咒的事。全篇张力最高点。
视觉
神自画面上方压下，身形以最粗剪影线勾出，三叉戟贯穿画面对角。神的形体内部几乎不刻线——留白的巨大形体比刻满的更压迫。下方船只极小，不足画面十分之一。海面排线在神的正下方呈放射状被推开。
镜头
横移与推近同时接近上限（唯一一次），并带向下的 y 位移。bg x −145 · y −20 · scale 1.08 · fg x +90
转场
沉降神的浪把画面压下去。
VIII

Sirens

塞壬

需出图
史事
为听塞壬的歌而不至丧命，奥德修斯以蜡封住同伴双耳，令他们把自己绑在桅杆上。他听见了，也挣扎了，但绳索没有松。
视觉
全篇最安静的一幅。海面平得反常，排线间距达到「微」档（12）。塞壬伏在左侧礁石上，形体不完整，被雾状的疏排线吃掉一半——不画清楚才可怕。桅杆与被缚的人在右侧，是画面唯一线条紧实的部分。天空完全留白。
镜头
强度全篇最低。镜头几乎不动——危险来自静止，不来自运动。bg x +50 · scale 1.02 · fg x −28
转场
洇墨opacity 1→0，blur 0→24px。歌声散开，意识失守。
Γ 卷三 · 渊与归 Nodes IX–XII · Abyss & Return
IX

Underworld

冥府

需出图
史事
为问归途，奥德修斯下到冥府，见到先知忒瑞西阿斯，也见到了自己已死去的母亲。他三次伸手拥抱，三次抓空。
视觉
纵向构图感最强的一幅：亡魂自下而上、层层叠叠向画面深处退去，愈远排线愈疏，最终化为空白。奥德修斯背影在前景下方，是唯一实线勾满的形体，其余全部以「疏」「微」两档处理。无地平线，无天空，上下皆暗。
镜头
全篇唯一以垂直位移为主的节点，横移极小——镜头在下沉。bg x −45 · y −70 · scale 1.06 · fg x +25 · y +45
转场
洇墨亡魂散去。连用两次洇墨，是全篇仅有的一次连用。
X

Scylla and Charybdis

斯库拉与卡律布狄斯

需出图
史事
海峡两侧，一边是六头怪斯库拉，一边是吞噬一切的漩涡卡律布狄斯。没有两全的选择——奥德修斯选择了斯库拉，用六个同伴换整条船。
视觉
构图被一分为二，全篇唯一的对称对峙式构图。左为绝壁与探出的多头剪影，右为巨大的螺旋漩涡——漩涡的排线呈同心弧，向心加密至最深。船夹在正中的窄缝里，小得可怜。这是密度最极端的一幅：两侧接近上限，中缝几乎全白。
镜头
横移取全篇最大值，推近中等偏上。第二个峰。bg x −150 · scale 1.06 · fg x +95
转场
沉降漩涡把画面吸下去。
XI

Return to Ithaca

重返伊萨卡

归乡.png · 需重裁
史事
二十年后，奥德修斯独自一人回到伊萨卡，同伴无一生还。他乔装成乞丐上岸，没有人认出他——除了那条老狗。
视觉
画面重新安静下来，但不同于第四节的平静：那时的平静是无知，此刻的平静是耗尽。岛的轮廓在远景，宫殿柱廊只露出一角。前景是一株扭曲的老橄榄树，树干排线沿纹理弯曲，是全画线工最繁密之处——二十年都刻在这棵树上。海面恢复均匀排线。
镜头
右移，微推近。幅度回落到接近开篇。bg x +75 · scale 1.02 · fg x −40
转场
揭页最后一次翻页。
XII

The End of Voyage

航程终点

需出图
史事
航程结束。武器放下，船被拖上岸，再不下水。长卷的另一端是家——而抵达之后，故事就不再需要镜头了。
视觉
全篇最空的一幅，排线覆盖率降到下限 35%。放下的头盔与倚在墙边的长矛占据前景，两件器物的线工极精细。海在远景，只有三四道极淡的水平以外角度的短线。人不出现。天空是全画最大的一片留白——这片留白是整卷的终点。
镜头
强度 16，全篇最低。镜头基本停住。bg x +30 · scale 1.01 · fg x −18
转场
定影opacity 1→0.35，不位移。画面淡下去但不移开，停在那里。全篇仅此一次。
